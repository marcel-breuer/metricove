# Changelog

Notable user-facing changes are recorded under `Unreleased` and moved into a dated version section when a release is prepared. Metricove follows Semantic Versioning. Before 1.0.0, releases use `0.MINOR.PATCH`: increment MINOR for new features or breaking changes, and PATCH for compatible fixes. The first stable release will use `1.0.0` once the public API and installation behavior are considered stable. See [the release guide](docs/releases.md) for release and image procedures.
